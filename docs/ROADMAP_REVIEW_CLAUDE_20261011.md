# Разбор дорожной карты — Claude, 11.10.2026

База: PLAN.md редакция 38, игра 0.6.0-a2 (+ PR #3). Это предложения для владельца и Codex. PLAN.md не правился: решение о порядке за владельцем.

## Главный вывод

Технический фундамент сильный: реальная карта, физика транспорта, перекрытия, пеший цикл, 341 тест. Отставание сейчас в двух местах:

1. **Приёмка на устройстве.** Около 20 пакетов подряд закрыты с пометкой «телефонная приёмка открыта». Оптимизации e1–e9 делались по CPU-адаптеру без реальных замеров. Первый браузерный замер (Claude, 11.10) сразу нашёл баг, который не видел ни один тест: город исчезал ~70% времени на медленном CPU.
2. **Глубина игрового цикла.** 6 типов вызовов, равновероятных, в случайных узлах. По отзывам жанра это главная причина бросить игру.

## B. Игровой процесс (по исследованию жанра)

Жанр и отзывы:
- **911 Operator.** Хвалят реальные карты и прогрессию найма. Главная жалоба — однообразие, затем перегруженный UI и потеря сохранений.
- **This Is the Police.** Раздражало, что экипаж нельзя перенаправить, пока он не вернулся. Штрафы быстро загоняют в безвыходную спираль. Кампания повторяет одни и те же сценарии.
- **Dispatch (AdHoc, 2025).** Хвалят подбор героя под требования задания по характеристикам, синергию пар (значимый бонус к успеху), мораль и события, которые меняют смену.

Предложения в порядке «польза/цена»:

| # | Предложение | Что уже есть в коде |
|---|---|---|
| B1 | **Вызовы по реальной статистике Эстонии.** Вес типа зависит от часа и места: ночью алкоголь и шум, вечером ДТП, у баров конфликты, во дворах семейные ссоры. Добавить самые частые реальные типы: человек в опьянении лежит на улице/остановке, шум в квартире, опасный/пьяный водитель, животное на дороге, вождение без прав, семейный конфликт. Ориентир доли по категориям ППА: общественный порядок ~31%, транспорт ~19%, насилие ~14%. | `TYPES` (6 типов), `spawnIncident` выбирает тип и узел равновероятно |
| B2 | **Требования вызова видны и влияют на исход.** Например: «Конфликт: переговоры + 2 сотрудника». В карточке назначения показать прогноз «подходит/рискованно». Тогда выбор экипажа становится решением, а не формальностью. | Специализации 0.5.2, совместимость пары 0.5.3-c1, навык и усталость — данные уже есть |
| B3 | **Перенаправление экипажа** с несрочного вызова (в пути, не на месте) на более срочный, с объяснением потерь. | `assign` принимает только `patrol`/`idle` |
| B4 | **Цепочки последствий.** Отпустили пьяного — через час он может стать участником нового вызова. Жалоба заведения влияет на доверие района. | Жители с историей и `linkResident` есть |
| B5 | **Защита от спирали поражения**, как в This Is the Police: минимальное финансирование, «тяжёлая смена» без мгновенного краха. | В 0.6.2 уже записано «банкротство не создаёт безвыходную кампанию» — оставить приоритетом |

**Порядок:** поднять **0.7.0** (полный цикл вызова: задержание, перевозка, отчёт) и **0.6.2** (бюджет, доверие, последствия) **выше 0.6.1** (топливо, износ, ливреи). Глубина основного цикла важнее гаража. B1–B3 можно сделать до 0.7 одним пакетом «Живые вызовы».

**0.8 (совместная игра на сервере)** — самый дорогой этап, и он конфликтует с офлайн-APK. Предлагаю после 1.0 одиночной игры или как отдельное ответвление.

## C. Техника

| # | Предложение | Детали |
|---|---|---|
| C1 | **Разблокировать сектор Paikuse/Tammiste.** HTTP 406 от Overpass — это не баг запроса. С апреля 2026 на перегруженных серверах действуют правила против массовых запросов. | Варианты: (а) описательный `User-Agent` + `Referer` и запрос в теле POST — по отчётам помогает, но 406 возвращались в июне 2026; (б) надёжнее — скачать выгрузку Estonia с Geofabrik и вырезать bbox локально через osmium. Без лимитов и воспроизводимо, с той же атрибуцией © OSM / ODbL. |
| C2 | **Сборка снимка города в Web Worker через OffscreenCanvas.** | Сейчас 0.8 с CPU на быстром ПК и в разы больше на телефоне режутся на кусочки в главном потоке. OffscreenCanvas 2D поддерживается Chrome и Android WebView. Нужно вынести из `render.js` базовую отрисовку без DOM. Средний рефакторинг, большой выигрыш плавности. |
| C3 | **Плиточный кэш вместо одного снимка** (например, 512×512 css px). | При пане и следовании за патрулём пересобираются только краевые плитки, а не весь экран с полями. |
| C4 | **Разрешение по умолчанию на Fold6.** | Codex уже ввёл бюджет 2 Мп. Проверить A1/A2-замером, хватает ли 1.5× на внутреннем экране. |
