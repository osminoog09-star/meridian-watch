# Город 2.0 — задание для Codex (владелец, 21.10.2026)

Владелец: «мне не нравится, как выглядит город: графика, дома, дороги, даже машины. Пускай Codex всё переделает — не цвета
поменяет, а создаст красивый и играбельный город». Свет, дождь и снег (Claude W2/G4) — оставить.

## Что построить
Вымышленный город-посёлок примерно на **15 000 жителей** (масштаб эстонского райцентра), спроектированный под игру, а не
срез реальной карты:
- **Центр**: площадь, ратуша, магазины, кафе/бар (ночные вызовы), автовокзал, школа, церковь, парк.
- **Жилые районы**: старый деревянный посад, панельный микрорайон (5-этажки, дворы с парковками), частный сектор.
- **Промзона**: склады, гаражный кооператив, лесопилка/завод, АЗС, депо; железная дорога со станцией.
- **Порт/берег или река** с мостом (одна-две точки, где город делится — интересно для маршрутов).
- **Дороги**: понятная сеть — главная улица, объездная, кварталы, дворовые проезды; перекрёстки, круг, переходы; выезды
  за город (пригород Claude G5 можно сохранить и подключить).
- **Службы** (каждая — отдельное здание с понятной точкой въезда и вывеской):
  - **Полицейский участок (небольшой)**: дежурная часть, патрульная служба (машины во дворе), **изолятор для задержанных**,
    кабинеты **участковых** и **следователя**.
  - **Опорный пункт скорой** (2 машины).
  - **Маленькая больница** с приёмным покоем.
  - **Пожарная часть**.
- **Машины**: новые модели — легковые разных типов, полицейская, скорая, пожарная, такси, автобус; аккуратные пропорции,
  колёса, фары.

## Как встроить, ничего не сломав
- Город в симуляции — `dist/city-data.js` (дороги, здания, области, берег) и `dist/geography.js` (узлы, районы по id
  `centre, ulejoe, raama, beach, mai, papiniidu, vana, raekula`). Эти id используются по всему коду (дом героя, сюжетные
  арки, автопарк 112, АЗС, тесты) — **оставить id, переложить их на новые районы**.
- Базы служб — `sim.js`: `HQ`, `HOSPITAL`, `FIRE_STATION`, `GBR_BASE` (+ `home.js HQ`) — поставить у подъезда новых зданий.
- Натив: `assets/city.json` (плитки 250 м) и `assets/map.json` собираются из данных (`export-map.mjs`, `geometry.mjs`);
  отрисовка — `scripts/city_geometry.gd`, `shaders/city.gdshader` (окна, крыши, асфальт, фонари, погода), `countryside.gd`.
- Новый город — новым набором данных (генератор в `tools/`, детерминированный), с проверками: все здания не на дорогах,
  дороги связные, каждый район достижим, базы на дорогах.
- Полицейский участок с отделениями — сначала как здание и места на карте; механику (изолятор, участковые, следователь)
  связать с тем, что уже есть: доставка задержанных (`custody`), роль «следователь» (`detective`), участковые — новая роль.
- Проверки: `npm test` (634/634) с обновлёнными ожиданиями, нативный аудит 51/51, длинные смены 7/7, рендеры
  `render_screens.gd` / `render_camera.gd` (портрет и альбом, день, ночь, снег).
- Выпуск: ветка `codex/city-v2` → PR в `claude/native-fixes` (и патч в `claude/release-m`), APK через CI, канал — как в
  `docs/CODEX_HANDOFF_20261018.md`. Каждый шаг — в `COLLAB_LOG.md`.
